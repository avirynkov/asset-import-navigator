# vite-react-svg-react

Proves: `?react` SVG imports navigate to the physical SVG (NAV-02, HOV-01/02).

Open `src/App.tsx`:
- F12 / Cmd+Click `Logo` or the `'./assets/logo.svg?react'` path → `src/assets/logo.svg`.
- F12 on `Badge` in the re-export → `src/assets/badge.svg`.
- Hover `Logo` → thumbnail, path and size.
